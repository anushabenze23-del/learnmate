Step 1 — IBM watsonx.ai Setup

1
Go to cloud.ibm.com → Create a free IBM Cloud account
2
Search for watsonx.ai Runtime → Create a Lite instance (free tier)
3
Go to Manage → Access (IAM) → API Keys → Create an API key → Copy it
4
Open watsonx.ai Studio → Create a project → Copy the Project ID from project settings
5
Paste both values into backend/.env (see table below)

backend/.env — Fill in your values

KeyWhere to get it
IBM_WATSONX_API_KEYIBM Cloud → Manage → IAM → API Keys
IBM_WATSONX_PROJECT_IDwatsonx.ai Studio → Project → Manage → General → Project ID
IBM_WATSONX_URLKeep default: https://us-south.ml.cloud.ibm.com
IBM_MODEL_IDKeep default: ibm/granite-13b-chat-v2 or use meta-llama/llama-3-70b-instruct
⚠️ Never commit .env to Git. It is already in .gitignore.

Step 2 — Backend (Flask)

Install

# Open terminal in the backend/ folder
cd backend

# Create virtual environment
python -m venv venv

# Activate (Windows PowerShell)
.\venv\Scripts\Activate.ps1

# Activate (Mac / Linux)
# source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

Run

python app.py
# → Running on http://127.0.0.1:5000
✅ Test it: open http://localhost:5000/api/health — you should see {"status":"ok"}

Step 3 — Frontend (React)

Install

# Open a NEW terminal in the frontend/ folder
cd frontend

# Dependencies already installed during scaffolding
# If needed:
npm install

Run

npm start
# → Opens http://localhost:3000

Quick Start (Both Servers)

# Terminal 1 — Backend
cd backend
.\venv\Scripts\Activate.ps1
python app.py

# Terminal 2 — Frontend
cd frontend
npm start
